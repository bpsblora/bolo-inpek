BPS KABUPATEN BLORA · PANDUAN WINDOWS

BOLO INPEK Updater

Panduan menggunakan aplikasi portable untuk pembaruan monitoring FASIH-SM dan dua Google Sheets. Baca bagian keamanan sebelum mengoperasikan data kantor.

1. Isi paket

BOLO-INPEK-Updater.exeAplikasi Windows portable, tanpa instalasi Python.
ambil_data_monitoring_inpek_v2.pyScript scraper internal. Hanya ada di paket internal yang diberikan pengelola; tidak ikut paket publik dari website.
PETUNJUK_LOGIN_SSO.txtPenjelasan cara mengisi email dan password SSO langsung pada aplikasi.
PANDUAN_UPDATER.htmlPanduan yang sedang dibaca.

OAuth Desktop JSON resmi dapat disertakan oleh pengelola dalam paket. Jika tidak tersedia, Updater otomatis mencarinya di folder aplikasi dan Download. Password SSO tidak disimpan di paket maupun di berkas konfigurasi.

2. Uji login Google (belum menjalankan FASIH)

Buka aplikasi.

Ekstrak ZIP ke folder yang bisa ditulis, lalu jalankan BOLO-INPEK-Updater.exe.

Klik “Uji Login Google”.

Jika file updater-oauth-desktop.json tersedia di folder aplikasi atau Download, Updater menemukannya otomatis. Bila tidak, pilih file resmi dari Google Cloud Console. Tes ini tidak membutuhkan VPN, script Python, atau password SSO.

Masuk menggunakan akun Google operator yang berwenang.

Baca detail izin Google Sheets dan persetujuan aplikasi. Jika Google menampilkan blokir atau aplikasi belum diverifikasi, hentikan dan laporkan kepada pengelola; jangan mengabaikan kebijakan keamanan instansi.

Periksa hasil.

Aplikasi hanya membaca identitas konfigurasi Firebase serta struktur dua spreadsheet. Tidak ada perubahan data, login SSO, ataupun scraping.

3. Pembaruan data FASIH (setelah diizinkan pengelola)

Mode pembaruan online produksi saat paket ini disiapkan masih dinonaktifkan untuk keselamatan data. Jangan menggunakan proses tulis sebelum pengelola menyatakan telah lulus pengujian VPN, SSO, OAuth, dan dua spreadsheet.

Siapkan aplikasi.

Letakkan script internal ambil_data_monitoring_inpek_v2.py dalam folder EXE. Updater mendeteksinya secara otomatis. File OAuth Desktop resmi dapat ikut dalam paket atau ditempatkan di folder Download. Tidak perlu membuat .env untuk mode Online.

Sambungkan VPN BPS terlebih dahulu.

Pastikan status Connected dan portal https://fasih-sm.bps.go.id/app dapat diakses melalui jaringan VPN BPS.

Isi email dan password SSO pada EXE.

Isi kolom Email/Username SSO dan Password SSO yang tersedia di aplikasi. Password ditampilkan sebagai titik dan dihapus dari form setelah proses dimulai. Centang konfirmasi VPN BPS, lalu pilih Perbarui Data FASIH setelah diizinkan pengelola.

Login Google, kemudian SSO FASIH.

Updater mengambil konfigurasi survei dan dua tujuan Sheets dari Firebase. Setelah FASIH dapat dijangkau melalui VPN BPS, aplikasi menggunakan email/password SSO dari form untuk login ke FASIH. MFA/OTP diselesaikan manual jika diminta.

Tinjau hasil pada dashboard.

Setelah proses berhasil, periksa waktu pembaruan serta kecocokan kedua spreadsheet sebelum menyatakan monitoring sinkron.

4. Jika proses tidak berjalan

FASIH tidak terjangkauPeriksa sambungan VPN BPS dan koneksi internet pada komputer yang digunakan. Updater membatalkan proses sebelum login SSO.
OAuth tidak dapat loginPeriksa file OAuth Desktop resmi, status verifikasi/izin Google, dan hak akses Firebase akun operator.
Google Sheets gagal dibukaPeriksa apakah akun login mempunyai izin ke kedua spreadsheet, dan Google Sheets API aktif.
Mode online tidak aktifPengelola belum mengaktifkan sinkronisasi produksi. Ini sengaja untuk menghindari perubahan data sebelum pengujian tuntas.

5. Keamanan berkas

Jangan membagikan password SSO, token Google, atau service-account credentials.json melalui website, GitHub, WhatsApp umum, atau paket ZIP publik. Batasi distribusi script internal kepada operator BPS yang berwenang.

Website BOLO INPEK hanya menyediakan sarana pengunduhan aplikasi. Browser tidak dapat menghubungkan VPN atau menjalankan EXE dari jarak jauh. Pengoperasian FASIH dilakukan secara manual oleh operator di PC Windows.
